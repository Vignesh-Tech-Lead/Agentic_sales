# User Acceptance Testing Checklist

## Sales
- [ ] Create lead manually.
- [ ] Review duplicate candidate and resolve safely.
- [ ] Assign lead to executive.
- [ ] View complete customer timeline.
- [ ] Receive AI qualification recommendation with evidence.
- [ ] Move opportunity through valid stages.
- [ ] Create and complete follow-up task.
- [ ] Draft and approve proposal.

## Marketing
- [ ] Build audience segment.
- [ ] Preview campaign recipient snapshot.
- [ ] Confirm suppression and consent filtering.
- [ ] Review AI personalization.
- [ ] Approve, schedule, pause and cancel campaign.
- [ ] Review bounce/complaint/unsubscribe metrics.

## Knowledge manager
- [ ] Upload SOP.
- [ ] Review scan/extraction/index status.
- [ ] Set document permissions.
- [ ] Test authorized and unauthorized search.
- [ ] Replace document with new version.
- [ ] Disable document and confirm retrieval exclusion.

## Administrator
- [ ] Configure IMAP/SMTP.
- [ ] Test connection and sync.
- [ ] Configure roles and permissions.
- [ ] Review audit log.
- [ ] Configure daily, weekly and monthly reports.
- [ ] Test backup restore evidence.

## Sign-off
Product owner, sales owner, marketing owner, security/privacy owner and technical owner sign off critical workflows before production.
